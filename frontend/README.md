# Finance App

A finance app that tracks your daily expenses and calculates your monthly and yearly spending, helping you understand where your money goes.

## Features

- Dashboard balance
- Income and expense cards
- Recent transactions

## Run locally

1. Go to the `frontend` folder.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.

## Built with

- React
- Vite
- CSS
